# Documentation Templates

## Release Notes Template

```markdown
# Release v[X.Y.Z] - [Release Date]

## Summary
[One paragraph overview of release]

## New Features
- Feature 1: [Description]
- Feature 2: [Description]

## Bug Fixes
- Fix 1: [Description]
- Fix 2: [Description]

## Breaking Changes
- [Breaking change 1]
- [Breaking change 2]

## Migration Guide
[Steps for users to upgrade]

## Contributors
- @user1
- @user2

## Security Advisories
[Any security-related changes or advisories]

## Known Issues
- Issue 1: [Workaround if any]
```

## Post-Mortem Template

```markdown
# Post-Mortem: [Incident Name]

**Date**: [Date]
**Duration**: [Time - Time]
**Severity**: [P1/P2/P3/P4]
**RCA Owner**: [Name]

## Executive Summary
[One paragraph summary of incident and impact]

## Timeline
| Time | Event | Owner |
|------|-------|-------|
| XX:XX | [Event] | [Person] |

## Root Cause
[Detailed explanation of root cause]

## Impact
- Affected services: [List]
- Users impacted: [Count/description]
- Business impact: [Cost/productivity loss]

## Prevention
[What could have prevented this]

## Detection
[How could we detect this faster]

## Mitigation
[What could reduce impact if happens again]

## Action Items
- [ ] [Action] (Owner: @name, Due: date)

## Attendees
@name1 @name2 @name3
```
