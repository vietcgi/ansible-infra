# Team Responsibilities Matrix

## Role Definitions

### DevOps Engineer
**Responsibilities**:
- Infrastructure provisioning and maintenance
- Ansible playbook development
- Backup and disaster recovery
- On-call support

**Skills Required**:
- Ansible expertise
- Linux administration
- Infrastructure as Code
- CI/CD pipelines

**Time Allocation**: 70% infrastructure, 20% automation, 10% on-call

---

### Senior Engineer
**Responsibilities**:
- Architecture decisions
- Code review and mentorship
- Complex problem solving
- Change approval authority

**Skills Required**:
- 5+ years experience
- System design
- Leadership
- Communication

**Time Allocation**: 50% development, 30% mentorship, 20% architecture

---

### Software Engineer
**Responsibilities**:
- Feature development
- Bug fixes
- Test coverage
- Documentation

**Skills Required**:
- Python/Ansible
- Testing frameworks
- Version control
- Problem solving

**Time Allocation**: 80% development, 10% testing, 10% learning

---

### Operations Support
**Responsibilities**:
- Monitoring
- Ticketing
- Documentation
- Runbook execution

**Skills Required**:
- Linux basics
- Customer service
- Technical writing
- Problem tracking

**Time Allocation**: 40% monitoring, 40% tickets, 20% documentation
