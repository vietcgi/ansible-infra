# Onboarding Guide

## First Day

**9:00 AM - Welcome**
- [ ] Meet team
- [ ] Workspace setup (desk, equipment)
- [ ] IT onboarding (laptop, accounts)

**10:00 AM - System Access**
- [ ] GitHub account
- [ ] Slack workspace
- [ ] Email configured
- [ ] SSH keys generated

**11:00 AM - Infrastructure Access**
- [ ] Clone ansible-infra repository
- [ ] Setup ansible-infra locally
- [ ] Test SSH access to staging

**1:00 PM - Lunch**

**2:00 PM - Documentation**
- [ ] Read README.md
- [ ] Read QUICK_START.md
- [ ] Skim ARCHITECTURE.md

**4:00 PM - Local Testing**
- [ ] Run `molecule test` locally
- [ ] Verify all tests pass
- [ ] Explore test output

---

## First Week

**Day 2**: Deep dive on Ansible
- [ ] Read Ansible documentation
- [ ] Study common role structure
- [ ] Understand variable hierarchy

**Day 3**: Infrastructure tour
- [ ] Meet with DevOps lead
- [ ] Understand current architecture
- [ ] Review deployment process

**Day 4**: Shadow developer
- [ ] Observe code review process
- [ ] Understand pull request workflow
- [ ] See change approval process

**Day 5**: First task
- [ ] Update documentation
- [ ] Submit first pull request
- [ ] Get code review feedback

---

## First Month

**Week 2**:
- [ ] Contribute to small bug fix
- [ ] Pair program with senior engineer
- [ ] Attend all team meetings
- [ ] Shadow on-call engineer (optional)

**Week 3**:
- [ ] Own one small feature
- [ ] Present learnings to team
- [ ] Review onboarding process feedback

**Week 4**:
- [ ] Complete first independent task
- [ ] Attend team retrospective
- [ ] Schedule 1:1 with manager
