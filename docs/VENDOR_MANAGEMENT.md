# Vendor Management & Assessment

## Vendor Categories

### Critical Vendors
- **Cloud provider** (AWS, Azure, GCP)
- **Backup service**
- **Monitoring SaaS**
- **Incident management**

**Review frequency**: Semi-annual
**Assessment required**: Yes, before approval

### High-Priority Vendors
- **Log aggregation service**
- **Secret management**
- **CI/CD platform**

**Review frequency**: Annual
**Assessment required**: Yes, before use

### Standard Vendors
- **Software licensing**
- **Training platforms**
- **Documentation tools**

**Review frequency**: As needed
**Assessment required**: Only if data-intensive

---

## Vendor Assessment Criteria

### Security
- SOC2 Type II certified? (or equivalent)
- Penetration testing conducted?
- Vulnerability disclosure policy?
- Incident response SLA?

### Compliance
- GDPR compliant?
- HIPAA (if applicable)?
- Data location guarantees?
- Export controls?

### Reliability
- 99.9%+ uptime SLA?
- Disaster recovery plan?
- Support response times?
- Escalation procedures?

### Operational
- API available for automation?
- Monitoring integration possible?
- Cost transparency?
- Migration assistance?

## Vendor Contract Review

**Before signing**:
- [ ] Security requirements met
- [ ] SLA terms acceptable
- [ ] Pricing audited
- [ ] Termination clauses reviewed
- [ ] Data ownership clause clear
- [ ] Insurance minimums adequate

**Annually**:
- [ ] Compliance status verified
- [ ] SLA achievement reviewed
- [ ] Performance evaluated
